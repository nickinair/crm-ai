## 一、六级字阶（现行标准）

全站文字字号**只允许以下 6 个值**。已在测试环境全量落地，迁移后 13 / 15 / 17 / 18 / 11px 全部清零。

| 级别 | 字号/字重 | 用途 | 实施后处数 |
|---|---|---|---|
| `text-xs` | **12px** / 400 | 辅助信息：KV 的 key（字段名）、时间戳、说明文字、标签 tag、徽标数字 | 90 |
| `text-base` | **14px** / 400 | **正文默认**：表格（表头+内容）、表单、下拉、按钮、菜单、KV 的 value、跟进记录内容、操作链接 | 108 |
| `text-md` | **16px** / 600 | 卡片标题、弹窗标题、分组标题、tab 文字、结果弹窗标题、侧边栏品牌名 | 34 |
| `text-lg` | **20px** / 700 | 详情页主体行：订单编号行、「当前线索 - L-XXX」标题行 | 4 |
| `text-xl` | **24px** / 700 | 页面标题（每页唯一）、客户详情页客户名、部门详情标题 | 3 |
| `num-stat` | **28px** / 700 | **仅限统计大数字**：首页指标卡、工作台今日数据卡数值 | 5 |

## 二、KV 信息展示专项（v1.1 新增）

详情页键值对展示的完整规定——key 与 value 通过**大小 + 明暗双重差异**拉开层次，value 一律不加粗。已在线索跟进页、客户详情页、订单详情页实施。

| 元素 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| key（字段名） | 12px | 400 | `#64748B`（暗石板灰） |
| value（值） | 14px | 400（**不加粗**） | `#F8FAFC`（主文字色） |

- 空值统一展示 `-`，不留白

```
线索来源          ← 12px #64748B
抖音直播间        ← 14px #F8FAFC 不加粗
```

## 五、开发约束（长期生效）

### CSS 变量（已加入 Layout.css `:root`）

```css
--fs-xs: 12px;     /* 辅助信息 */
--fs-base: 14px;   /* 正文默认 */
--fs-md: 16px;     /* 卡片/弹窗标题 */
--fs-lg: 20px;     /* 详情页主体行 */
--fs-xl: 24px;     /* 页面标题 */
--fs-stat: 28px;   /* 统计大数字专用 */
```

### 强制规则

1. 文字字号只允许 **12 / 14 / 16 / 20 / 24 / 28**，Code Review 见到其他值一律打回
2. **28px 仅限统计数字**；最小文字 12px，禁止 11px 及以下
3. 字重：12/14px 常规 400（强调 500）；16px 及以上标题 600–700；**KV 的 value 不加粗**
4. KV 的 key 颜色统一 `#64748B`，value 用主文字色

### 新页面自查清单

- [ ] 页面标题 24px、每页唯一
- [ ] 表格/表单/按钮全部 14px
- [ ] key 与时间戳 12px + `#64748B`；value 14px 不加粗
- [ ] 卡片与弹窗标题 16px
- [ ] 提交前全页搜索 `font-size` / `fontSize`，确认无六值之外的字号
